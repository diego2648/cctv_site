# Sitio web — Seguridad, CCTV, Automatización y Redes

Landing page responsive creada como propuesta visual para una microempresa que instala:
- Cámaras CCTV
- Cercas eléctricas
- Portones automáticos
- Timbres y videoporteros
- Control de acceso
- Cableado estructurado

## Abrir
Abre `index.html` en el navegador.

## Personalizar datos del negocio
Edita al inicio de `script.js` el objeto `BUSINESS_CONFIG`:

```js
const BUSINESS_CONFIG = {
  name: 'Seguridad & Redes',
  phoneDisplay: '00 0000 0000',
  whatsapp: '5210000000000',
  serviceArea: 'Área de cobertura: personalizable'
};
```

### WhatsApp
Usa el número en formato internacional, sin `+`, espacios o guiones.
Ejemplo México: `5217221234567`.

## Efectos incluidos
- Preloader / animación de carga
- Hover con brillo dinámico
- Tarjetas con efecto 3D tilt
- Animaciones de entrada con IntersectionObserver
- Botones magnéticos
- Cursor personalizado
- Fondo animado con partículas y conexiones
- Hero con parallax de mouse
- Menú desplegable tipo mega-menu
- Selector interactivo de inmueble con puntos de cámaras
- Carrusel automático de marcas
- FAQ tipo acordeón
- Formulario que genera mensaje de WhatsApp

## Marcas
Los logotipos de Hikvision, Dahua, Epcom y Panduit fueron recortados de la imagen proporcionada por el usuario y se encuentran en `assets/`.
